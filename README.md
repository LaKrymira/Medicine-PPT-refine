# Medicine-PPT-refine

把医学教学课件整理成便于理解、记忆和背诵的结构化资料。

本仓库仅保存可复用的 skill 方法与模板，不包含课程原件、课堂截图、学生笔记成品或个人环境配置。

## Skill

入口：[medicine-ppt-refine / SKILL.md](skills/medicine-ppt-refine/SKILL.md)

核心流程：

1. 通览课件，找到目录、学习要求、总结及习题；细读前按主题归并页面、拆分内容子任务。
2. 结合文字、页面图像和教师强调色，先把每个模块讲完整，再精炼。
3. 概念统一前置，同类知识集中比较；分类用导图，区别用表格，过程用流程图。
4. 用稳定的文字颜色标记核心、条件与易错点；保留必要限定，服务于背诵。
5. 保留识图、结构演示和课后题截图，并给出简短解析。
6. 外部资料与课件不一致时，标明课程口径，在相关内容下方加有来源的批注。
7. 对照原页和习题检查覆盖，渲染检查最终文件。

## 使用示例

在支持加载 skill 的助手中加载本仓库的 `skills/medicine-ppt-refine`，提供课件并说明输出需求，例如：

> 请按 medicine-ppt-refine 总结这份医学课件。先找知识主线并归并主题，所有概念定义前置，用颜色突出背诵重点；保留关键原图和习题截图并给解析。外部知识与课件有出入时保留并标明课程口径，下方加批注及来源。输出可读的 PDF 和可编辑文字版。

也可以直接阅读入口文件，把方法用于人工整理。具体文件格式、字号和篇幅依课件与使用者要求调整。
