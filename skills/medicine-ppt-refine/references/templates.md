# 整理模板

用于较长课件的主题拆分、来源追踪及整合。按任务删减字段，不要求原样出现在最终资料中。

## 主题子任务

| 字段 | 要记录什么 |
| --- | --- |
| 主题与边界 | 要讲清什么，与其他主题如何区分 |
| 来源页面 | 文件名及原页序；允许不连续区间 |
| 核心问题 | 读完应能回答的问题 |
| 必要知识 | 概念、分类、机制、区别、限定与例子，按实际内容选择 |
| 强调与原图 | 局部强调色、识图要求、截图页与关联标签 |
| 前后依赖 | 需要先懂的概念；共享概念的统一解释位置 |
| 学习要求与原题 | 原有等级、相关题号及答案位置 |
| 输出形式 | 短句、对照表、导图、流程或原图 |
| 缺口与差异 | 尚未展开的内容、待核实处、检索出处 |
| 完成标准 | 核心问题有答案、必要内容完整、来源可追溯 |

## 就地批注

> **PPT表述（原页 …）：** 保留相关课程口径。
>
> **批注｜范围／版本／待核实等：** 用一两句说明差异、必要条件和如何理解。〔来源名称、年份／版本、可点击链接〕

明确的算术错误可给出独立验算，无须为简单计算制造外部引文。未解决的争议不输出确定性“纠正”。

## 原题解析

1. 保留题号、完整题干、选项及相关图示的截图。
2. 紧邻写“整理答案”，若教师给过答案另标“教师答案”。
3. 解释决定答案的条件，必要时对比易混项。
4. 给出相应知识模块／成品页定位。
